# 自主交付格式改造验收

日期：2026-10-12。

交付面板已由预设勾选改为用户配置封装、编码、档位、位深、色度采样、Alpha、输出色彩、数据范围、图像压缩和质量控制。支持 1–20 个独立目标；共用画面尺寸、帧率及时间码。新流程不需要保存或查找预设。

兼容性规则来自共享核心和本机编码器像素格式查询。最近修改的字段优先，合法设置保留；自动修正项目以字段和值提示。HDR 与位深、Alpha 与编码档位、封装与编码、MXF 与帧率均参与联动。EXR/TIFF 预乘 Alpha 切换到 PNG 时改为直通 Alpha，保留透明度。无效或仍在更新的设置不会提交。

## 实测结果

- Python：62 项通过，含新的联动、CLI 明确参数冲突、无预设任务冻结和原生编码测试。
- Ruff / mypy：通过，21 个源模块类型检查通过。
- TypeScript / ESLint / Vite 生产构建：通过。
- Chrome：8 项流程通过，覆盖原生键盘快速选择、目标间独立性、重复配置、MXF 帧率限制、数值错误、慢响应与断连重试、序列导出及 390 px 窄屏。
- Axe：所测工作区和 MCP 页面无 WCAG 2.2 相关违规；独立可访问性命令通过。
- MCP：stdio 和 Streamable HTTP 均暴露 56 个工具，Schema 完整，返回一致的联动选项。
- 仅通过 MCP 实际生成 320 × 180、30 fps、3 帧的 H.264、ACEScg EXR float、ProRes 4444 Alpha 和 HEVC Main10 PQ；四项原生输出检查通过。原生图像、Alpha 检查、版本冻结、重复提交和不兼容参数拒绝均通过，没有保存自定义预设。
- 界面静态审查：0 错误、0 警告。DESIGN.md 官方检查：0 错误、0 警告。生成 token 无漂移。

macOS 无头 Chrome 无法自动驱动系统原生菜单的方向键，在纯 HTML select 上亦复现；已用真实键盘快速选择和标准列表操作验证联动，并检查菜单打开操作。菜单外观及其原生交互由操作系统管理。

## 接口及使用

主要接口：`get_delivery_options`、`validate_delivery_configuration`、`estimate_delivery`、`submit_configured_delivery`。CLI 的 `render` 支持直接格式参数；通用 `call` 可使用全部接口。旧预设 API 仅用于已有脚本和任务兼容，网页不再提供预设选择。

刷新本地工作台后使用；MCP 客户端重新连接可获取新增工具。详见 [README](../README.md)、[交互约定](../UX-CONTRACT.md)。本轮媒体、截图和隔离测试工作区已清理；保留本记录及小型静态界面审查 JSON。此前 4K/8K/120fps 数据属于历史验收，本轮未重跑大型渲染。
