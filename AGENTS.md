# ChromaScript working instructions

- Work in this repository; keep workspace outputs and virtual environments out of Git.
- The shared operation registry is the API contract. Every product capability must have an equivalent MCP tool and CLI call.
- Use Python 3.12 and the locked environment. Preserve strict input models and rational frame rates.
- Add/update code comments when editing code, especially color science, alpha association, sampling, time, and recovery.
- Keep original ACEScg float values separate from display-rendered previews. Alpha never enters OCIO color processing.
- Never certify precision or codec support from names alone. Record actual decoded properties and exact verification combinations.
- Update DESIGN.md and generated UI tokens together. Follow UX-CONTRACT.md; preserve drafts and revision conflicts.
- Run focused tests, ruff, mypy, frontend typecheck/lint/build, and relevant browser checks.
- Rendering is local/offline. Do not add cloud APIs, paid models, audio, 3D, DCP or IMF without a new request.
